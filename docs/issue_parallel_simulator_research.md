# 逆向 RMUA 模拟器场景生成和物理，支撑高并发训练

## 目标

基于本地模拟器 12.0.0.5，提取并验证 seed 到场景的映射、障碍物和风、PWM 动力学、传感器与时序规则，建立可复现的官方对照，为 LiDAR/IMU/PWM 高并发训练环境提供数据和模型。区分官方运行结果与训练近似，不将调试真值作为比赛控制输入。

## 工作项

- [ ] 核对模拟器、资源和工具版本及哈希，建立隔离环境和可重复采集入口。
- [ ] 追踪每类门的创建和变换；确认 seed 是否影响数量、位置、姿态、尺寸及过门判定。
- [ ] 追踪车辆、细条障碍物的生成、碰撞体、运动、触发条件及随机流；比较同 seed 重复和跨 seed。
- [ ] 追踪风区的位置、大小、风向风速、时间变化、随机源及对动力学的作用；在实际风区采样。
- [ ] 还原 PWM 输入、频率/保持、PWM 到电机、力矩、刚体积分、气动阻力及碰撞规则；通过阶跃和闭环实验标定。
- [ ] 审计 LiDAR、IMU、GPS、相机的几何、噪声、时钟和各环节延迟、抖动、丢帧。
- [ ] 实现只用于开发的运行时观测：按仿真时间记录对象 ID、类型、变换、速度、风和事件；独立保存版本/配置/seed/源码哈希。
- [ ] 验证 `-nullrhi` 模式的动态障碍、风、碰撞和控制行为，以及 reset/seed、时间步进、独立 ROS master 和加速模式。
- [ ] 基于恢复规则制作批量环境原型；对未还原部分明确使用实测重放或分布近似，禁止宣称相同 seed 必然对应官方相同场景。
- [ ] 在留出 seed 上比较对象轨迹、风、动力学响应、观测与延迟分布、碰撞/任务事件、策略成功率及吞吐。

## 现有证据与边界

- 已提取地图中的 12 个 `RouteGate` 静态对象；尚未证明其覆盖所有可见门。
- 同图 seed 123/456 选取的部分同视角门图像相近，不构成所有门在所有 seed 下固定的证明。
- 起点多 seed 风采样为零，不代表风区的风不随 seed 变化。
- `-nullrhi` 两实例收到了 IMU 和非零 LiDAR，PWM 起点悬停能升空；相机图像为 0×0。尚未验证风区、动态障碍或碰撞等价。
- 官方客户端内部状态和 Score 不代表官方最终裁判计分。

## 验收

交付可复现脚本、场景/物理模型、原始证据与误差报告；能清晰说明哪些机制已经从代码和运行实验双重确认，哪些仍为近似或未知。至少覆盖固定版本、同 seed 重复、跨 seed 和未参与拟合的留出场景；记录失败结果及传感器/控制时间。
